# Rta Living

Luxury smart-home platform merging **AI personalisation** with IoT and Vastu philosophy.

🌐 **Live:** [rtaliving.com](https://rtaliving.com)

## Stack
- **TypeScript** monorepo orchestrated with **Turborepo**
- `apps/web` — the web application
- `packages/tokens` — design tokens / design system
- React · CSS

## What it does
A connected-home experience that personalises lighting, climate and ambience using AI, designed around principles of harmony and well-being.
